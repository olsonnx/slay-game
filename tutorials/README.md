# Editable tutorials

Author tutorials with **Tutorial Editor.cmd** in the project root. See [the guide](../docs/tutorial-editor.md).

The tool installs `armies.json`, `economy.json`, `construction.json`, `logistics.json`, `conquest.json`, `magic.json`, `exploration.json` or `practice.json` here. Maps and exercise positions are embedded. Missing or invalid topic files fall back to the built-in topic. A `.json.bak` file retains the previous installed version; it is not loaded or exported. Old `basics`, `intermediate` and `advanced` overrides are no longer used.

The eight built-in chapters follow the cities and logistics rules. Cities and supply lines teaches forward recruitment, editing city names, road previews and prices, a six-hex Knight march, and joining an existing road. Other chapters cover 5/4/3 movement, merging, spent upgrades, permanent towers and roads, flat bridge prices, upkeep, recruitment areas and safe tree growth.
