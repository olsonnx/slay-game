# Editable tutorials

Author tutorials with **Tutorial Editor.cmd** in the project root. See [the guide](../docs/tutorial-editor.md).

The tool's **Use in game** action installs `basics.json`, `intermediate.json` or `advanced.json` here. Maps and steps are embedded in each file. Missing or invalid category files fall back to the built-in lesson. A `.json.bak` file retains the previous installed version; it is not loaded or exported.
