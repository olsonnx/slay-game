# Editable tutorials

Author tutorials with **Tutorial Editor.cmd** in the project root. See [the guide](../docs/tutorial-editor.md).

The tool installs `armies.json`, `economy.json`, `construction.json`, `conquest.json`, `magic.json`, `exploration.json` or `practice.json` here. Maps and exercise positions are embedded. Missing or invalid topic files fall back to the built-in topic. A `.json.bak` file retains the previous installed version; it is not loaded or exported. Old `basics`, `intermediate` and `advanced` overrides are no longer used.
